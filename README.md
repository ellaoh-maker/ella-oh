# 경영전략팀 회고록 페이지

매달 팀원들이 업무 / 잘한 점 / 아쉬운 점 / 추가 의견을 적는 웹페이지입니다.
서버 없이 동작하는 정적 페이지라서 깃허브 페이지(GitHub Pages)에 그대로 올리면 됩니다.

## 구성 파일
- `index.html` — 회고록 페이지 본체 (열어서 바로 사용 가능)
- `data.json` — 실제 데이터가 저장되는 파일 (8월 회고 원본 + 9월 빈 템플릿 포함)

## 화면 사용법
- 페이지를 열면 기본은 **보기 전용** 화면이에요. 그 달에 팀원들이 적은 내용이 그대로 나열됩니다.
- 우측 상단 **"내용 입력하기"** 버튼을 누르면 편집 모드로 바뀌어 이름/내용을 직접 채우거나 고칠 수 있어요.
- 편집 모드에서는 각 사람 카드 오른쪽 위 **▲ / ▼** 버튼으로 순서를 자유롭게 바꿀 수 있고, 새로 달을 추가하면 방금 있던 달의 순서를 그대로 이어받습니다 (특정 사람이 항상 맨 위에 고정되지 않아요).
- 다 쓰면 **"완료 (보기 전용으로)"** 버튼으로 다시 보기 화면으로 돌아가면 됩니다.

## 깃허브 페이지에 올리는 방법
1. 새 저장소를 만들고 `index.html`, `data.json`을 그대로 올립니다 (커밋 & 푸시).
2. 저장소 **Settings → Pages**에서 Source를 `main` 브랜치, 루트(`/`) 폴더로 설정합니다.
3. 몇 분 뒤 `https://{계정명}.github.io/{저장소명}/` 주소로 접속하면 페이지가 뜹니다.

## 자동 저장 연결하기 (추천)
페이지 안 **"자동 저장 연결 (깃허브)"** 패널에서 한 번만 연결해두면, 이후로는 수정할 때마다
자동으로 저장소의 `data.json`이 커밋돼요. 파일을 내려받았다가 다시 올리는 과정이 필요 없어져요.

1. 깃허브에서 본인 계정 **Settings → Developer settings → Personal access tokens → Fine-grained tokens**로 이동합니다.
2. **Generate new token**을 누르고, Repository access를 이 저장소 하나만 선택합니다.
3. Permissions에서 **Contents: Read and write**만 켭니다. 만료일(Expiration)도 적당히 설정해주세요.
4. 생성된 토큰(`github_pat_...`로 시작)을 복사합니다.
5. 페이지의 "자동 저장 연결" 패널에 저장소(`계정명/저장소명`, 예: `ellaoh-maker/ella-oh`), 브랜치(`main`), 파일 경로(`data.json`), 토큰을 입력하고 **연결하기**를 누릅니다.
6. "연결됐어요" 메시지가 뜨면 끝입니다. 이제부터 편집할 때마다 잠시 후 자동으로 커밋돼요.

> **주의**: 토큰은 이 브라우저에만 저장되고 비밀번호처럼 다뤄야 해요. 다른 사람과 공유하지 마시고,
> 저장소 하나에만 쓰기 권한을 준 fine-grained 토큰만 쓰는 걸 추천해요. 자동 저장을 연결한 사람은
> 각자 본인 컴퓨터/브라우저에서 한 번씩 이 과정을 거쳐야 해요 (토큰이 서로 공유되지 않아요).

## 자동 저장을 연결하지 않았을 때 (수동 백업)
이 페이지는 서버나 로그인이 없기 때문에, 자동 저장을 연결하지 않으면
**입력한 내용은 각자의 브라우저에만 임시 저장**됩니다. 팀 전체가 같은 내용을 보려면 아래 순서를 따라주세요.

1. 페이지를 열면 저장소의 `data.json`을 자동으로 불러옵니다.
2. 각자 해당 월 탭에서 편집 모드로 전환해 본인 칸을 작성합니다. (탭 옆 `+ 새 달`로 다음 달 페이지 생성 가능)
3. 작성이 끝나면 **"데이터 저장" → data.json 저장** 버튼으로 최신 `data.json`을 내려받습니다.
4. 받은 `data.json`을 저장소에 덮어쓰고 커밋 · 푸시하면, 다음에 페이지를 여는 모든 사람이 최신 내용을 보게 됩니다.

> 여러 명이 동시에 작성 중이라면, 마지막에 저장한 사람의 내용이 기준이 되니
> 가급적 한 사람이 취합해서 커밋하는 방식을 추천드려요 (예: 매달 말 작성 담당자 지정).

## 로컬에서 확인하기
`index.html`을 더블클릭해서 바로 열면 브라우저 보안 정책상 `data.json`을 자동으로 못 불러올 수 있어요.
이럴 땐 페이지 안의 **"data.json 불러오기"** 버튼으로 직접 파일을 선택해서 불러오면 됩니다.
(깃허브 페이지처럼 `https://`로 접속하면 자동으로 잘 불러와집니다.)

## 각 달 내용 내보내기
각 월 탭 하단 "이번 달 내보내기"에서 원본 엑셀과 같은 표 형식(마크다운)으로 복사하거나
`.md` 파일로 받을 수 있습니다. 위키나 노션 등에 붙여넣기 좋아요.

## 참고: 깃허브 페이지 접근 범위
private 저장소여도 깃허브 페이지 자체는 기본적으로 "링크를 아는 사람은 누구나" 접근 가능한 상태예요.
이 회고록에는 은행명, 딜 코드네임 등 민감한 내용이 들어가니, 조직 플랜에 접근 제한 기능이 있는지 먼저 확인하거나
없다면 어디까지 적을지 팀과 미리 정해두는 걸 추천드려요.
