매달 각자의 업무 · 잘한 점 · 아쉬운 점 · 하고 싶은 말을 남겨두는 페이지예요.

자동 저장 연결 (깃허브)

깃허브 저장소랑 한 번 연결해두면, 수정할 때마다 자동으로 data.json이 커밋돼요. 매번 파일을 내려받고 다시 올릴 필요가 없어져요.

아직 연결 안 됐어요 — 연결 전까지는 아래 수동 저장을 써주세요.

토큰은 이 브라우저에만 저장되고 깃허브로 그대로 전달돼요. 저장소 하나에만 쓰기 권한을 준 fine-grained personal access token을 만들어서 쓰는 걸 추천해요 (Contents: Read and write 권한, 만료일 설정).

이번 달 내보내기

원본 엑셀과 같은 표 형식(마크다운)으로 정리해 드려요. 복사하거나 파일로 받아서 공유하세요.

수동 백업 (자동 저장 연결 안 했을 때)

위 자동 저장을 연결했다면 이 부분은 안 써도 돼요. 연결하지 않았다면, 이 페이지는 서버가 없어서 입력한 내용이 내 브라우저에만 임시 저장돼요. 아래 data.json 저장으로 파일을 받아 저장소의 data.json을 교체하고 커밋 · 푸시해주세요. 다른 사람이 올린 최신 data.json을 받았다면 data.json 불러오기로 반영할 수 있어요.

브라우저에 임시 저장된 내용을 불러왔어요.
회고는 형식보다 꾸준함이에요. 부담 없이 적어주세요.
